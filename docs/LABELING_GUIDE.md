# Labelling guide

Schema version **1.0.0**. Generated by `joblens labeling-guide` from the field descriptions in `src/joblens/schema.py`: the schema is the single source of truth, so edit descriptions there and regenerate. The same text instructs the teacher model and the human reviewer.

General rules: label only what the posting states; use `unknown`, `not_mentioned`, `null` or `[]` when it does not say; do not guess from the company or the job family.

## Fields

### `title`

Job title as written, without gender suffixes like '(m/w/d)' or '(f/m/x)'.

### `company`

Hiring company as written. For staffing agencies use the agency name unless the client is named. null if absent.

### `locations`

All work locations mentioned. Empty list if none is given.

  - `city`: City as written in the posting, without postcode or district ('Nürnberg, Mittelfranken' -> 'Nürnberg'). null if only a country/region is given.
  - `country`: ISO 3166-1 alpha-2 code, e.g. 'DE', 'AT', 'CH'. Use 'DE' for German cities. null if unknown.

### `remote_policy`

remote = fully remote ('100% remote', 'Remote in Deutschland'); hybrid = some days at home ('2 Tage Homeoffice', 'mobiles Arbeiten möglich', 'hybrid'); onsite = explicitly on site or field/shift work that cannot be remote ('vor Ort'); unknown = not stated.

### `seniority`

From the title or explicit wording. intern = Praktikum/internship/Werkstudent; junior = 'Junior', 'Berufseinsteiger', 'Absolvent', 0-2 years; mid = 2-5 years or 'Professional' without senior wording; senior = 'Senior', 'Lead' (individual), 5+ years; staff_plus = 'Staff', 'Principal', 'Head of', 'Director', 'Bereichsleiter'; unknown = no signal. Do not infer seniority from salary alone.

### `min_years_experience`

Minimum years of experience stated as a number: '3+ Jahre' -> 3, 'mindestens 5 Jahre' -> 5, '2-4 years' -> 2. Vague wording like 'mehrjährige Erfahrung' or 'several years' -> null (not a number).

### `required_skills`

Hard skills, tools, certificates and licences that are required ('Voraussetzung', 'must have', 'Ihr Profil'). Lowercase; synonyms normalised ('k8s' -> 'kubernetes'). No soft skills ('teamfähig'), no languages (those go to languages_required).

### `nice_to_have_skills`

Skills marked optional: 'wünschenswert', 'von Vorteil', 'idealerweise', 'nice to have', 'a plus', 'bonus'. Same normalisation as required_skills.

### `languages_required`

Spoken/written languages that are required. Optional languages ('Englisch von Vorteil') are not listed.

  - `language`: Language name in lowercase English: 'german', 'english', 'french'. 'Deutschkenntnisse' -> 'german'.
  - `level`: basic = 'Grundkenntnisse', A1-A2, 'basic'; good = 'gute Kenntnisse', B1-B2, 'good'; fluent = 'fließend', 'verhandlungssicher', 'sehr gut', C1-C2, 'fluent', 'business fluent'; native = 'Muttersprache', 'native'; unspecified = the language is required but no level is stated.

### `english_sufficient`

Can someone with English only do this job? Derived: 'no' if German at level good or above is required (enforced by the validator). 'yes' if the posting says English is enough or the working language is English and German is optional. Otherwise 'unclear'.

### `contract_type`

permanent = 'unbefristet', 'Festanstellung', 'permanent'; fixed_term = 'befristet', 'fixed-term', 'Elternzeitvertretung'; freelance = 'freiberuflich', 'Freelancer', 'contractor'; internship = 'Praktikum', 'Pflichtpraktikum'; working_student = 'Werkstudent', 'working student'; unknown = not stated.

### `contract_duration_months`

Duration in months for fixed-term, internship or working-student contracts: 'befristet auf 2 Jahre' -> 24, '6-monatiges Praktikum' -> 6. null otherwise.

### `salary`

Only explicit figures. null if no number is given ('attraktive Vergütung', 'nach Tarif' without a figure).

  - `min`: Lower bound as a plain number in the stated currency and period. '65.000 €' -> 65000; '4.500,50 €' -> 4500.5. For a single figure set min = max.
  - `max`: Upper bound; same rules as min.
  - `currency`: ISO 4217 code: '€'/'EUR'/'Euro' -> 'EUR', 'CHF', 'GBP', 'USD'.
  - `period`: year ('p.a.', 'jährlich', 'brutto/Jahr'), month ('monatlich', 'pro Monat'), hour ('Stundenlohn', '€/h', 'pro Stunde').

### `visa_sponsorship`

yes = 'Visa sponsorship available', 'Unterstützung beim Visum'; no = 'no visa sponsorship', 'EU work permit required'; not_mentioned otherwise.

### `relocation_support`

yes = 'relocation package', 'Umzugshilfe', 'Umzugskostenpauschale'; no = explicitly excluded; not_mentioned otherwise.

### `application_deadline`

ISO date YYYY-MM-DD of an explicit deadline ('Bewerbungsfrist: 15.12.2026' -> '2026-12-15'). null if none.

### `posting_language`

Main language of the posting text: 'en' or 'de'.
